REPOSITORIO Y VERSIÓN PARA PROBAR

Si antes de la reunión desea ver la aplicación en funcionamiento, le
dejo el enlace al repositorio público con la versión más reciente:

  Repositorio:  https://github.com/dashy2004/LosasPlus
  Release v0.6: https://github.com/dashy2004/LosasPlus/releases/tag/v0.6.0

Está publicada como ejecutable único (single-file self-contained) para
Windows 10/11 de 64 bits, no requiere instalar .NET ni nada adicional.


PASOS PARA PROBAR LA APLICACIÓN

  1. En la página de la Release v0.6.0, descargar "LosasPlus.exe"
     (aproximadamente 190 MB).

  2. Ejecutarlo. La primera vez Windows mostrará el aviso azul
     "Windows protegió tu PC" (porque el ejecutable aún no está
     firmado): hacer clic en "Más información" y luego en "Ejecutar
     de todas formas".

  3. Dentro de la aplicación, ir al menú:
        File → Engine → Examinar Losas.exe...
     y apuntar a su copia local de Losas.exe. Solo se hace una vez —
     la app recuerda la ubicación.

  4. Abrir un archivo .DL existente con:
        File → Abrir .DL legacy...
     La aplicación cargará todas las losas, bordes adicionales y
     parámetros del sistema en una interfaz tabular moderna.

  5. (Opcional) Recorrer las pestañas del panel izquierdo:
        • Explorador      — proyectos recientes.
        • Editor          — DataGrid con cálculo en vivo (Cond 1D/2D,
                            espesor h_calc, h_eq, αx/αy/αm, etc.).
        • Diagrama        — esquema visual del sistema.
        • Salida .TXT     — visor del .txt del motor (dos vistas:
                            Texto resaltado y Tabla editable).
        • Validación      — chequeos R-001 y ACI 318 automáticos.
        • Configuración   — temas y atajos personalizables.

Si en cualquier paso encuentra un detalle que no funciona como esperaba,
no se preocupe — anótelo y lo conversamos en la reunión. La aplicación
también incluye un "Doctor de archivos .DL" que detecta y repara
automáticamente los formatos legacy más comunes.
