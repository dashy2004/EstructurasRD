# Entradas del cálculo de losas

En esta carpeta, **Add file → Upload files** admite los dos JSON de un caso sintético: `proyecto.json` con los paños exportados y `usos.json` con las asignaciones por marca. Confirme ambos archivos en la rama para iniciar el cálculo. Los expedientes reales se procesan en una copia privada. [Guía, ejemplo y resultados descargables](../docs/calculo-losas-github.md)
